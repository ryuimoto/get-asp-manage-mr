# Rentracks 広告案件 一覧取得（Chrome 拡張機能）

`https://manage.rentracks.jp/manage/bill_index/index` でキーワード検索した広告案件一覧を、ページネーションを辿って **全件** 取得し、CSV としてダウンロードする Chrome 拡張機能。

## インストール手順

1. Chrome で [chrome://extensions](chrome://extensions) を開く
2. 右上の「**デベロッパーモード**」をオンにする
3. 「**パッケージ化されていない拡張機能を読み込む**」を押す
4. このフォルダ（`get-asp-manage-mr/`）を選択
5. ツールバーに拡張機能アイコンが表示される（ピン留め推奨）

## 使い方

1. Rentracks の管理画面にログイン
2. `bill_index` でキーワード検索を実行
3. **表示件数を「100」に変更**（fetch 回数を減らせて速い）
4. ツールバーのアイコンをクリック
5. 「保存」ダイアログで CSV を保存
6. Google スプレッドシートで「ファイル → インポート → アップロード」で取り込み

実行中はアイコン右下のバッジに `2/8` のように進捗ページ数が表示される。
完了時は `OK`、エラー時は `ERR` がバッジに出る。

ページサイズが 100 以外の場合は確認ダイアログが出る（「このまま続行しますか？」）。

## 出力 CSV のカラム

1案件 = 1行。先頭固定の列は以下の順:

```
プロダクトID, 案件名, LP_URL, 提携状態,
広告主ID, 広告主名,
報酬形態, 報酬額, 承認有効期限, 再訪問有効期限,
承認率, CVR, CTR, EPC,
掲載_リスティング, 掲載_ディスプレイ広告, 掲載_FB集客, 掲載_twitter集客,
掲載_メルマガ集客, 掲載_ポイントサイト, 掲載_本人申込, 掲載_その他ソーシャル,
掲載_ITP対応, 掲載_拒否理由表示,
（その他 掲載_xxx 列が出てきたら自動追加）,
サイトの紹介
```

- 文字コードは UTF-8 + BOM（Excel / Google スプレッドシートで文字化けしない）
- 報酬額の「,」や紹介文の改行はダブルクォート囲みで保護される

## ファイル構成

| ファイル | 役割 |
|---|---|
| [manifest.json](manifest.json) | MV3 設定（permissions: activeTab / scripting / downloads） |
| [background.js](background.js) | アイコンクリック起動 / CSV ダウンロード / 進捗バッジ |
| [content.js](content.js) | 全ページ巡回 / `.advtable2` カードのパース / CSV 生成 |

## 設計メモ

- ページサイト構造は **「`<table class="advtable2">` というカードがDOM上に並ぶ」** 形（一覧テーブル型ではない）
- ページャ URL: `/manage/bill_index/index/{N}`（CodeIgniter 風 path 型 / 1ページ目は番号なし）
- 検索条件はサーバ側セッションに記憶されるため、検索後に GET `/index/{N}` で同じ検索結果のページ N が返る
- fetch / DOMParser はページコンテキスト（content.js）側で実行 — Service Worker は `DOMParser` を持たないため
- fetch 間に 300ms スリープ

## トラブルシューティング

| 症状 | 対応 |
|---|---|
| バッジに `NG` | URL が `manage.rentracks.jp/manage/bill_index*` ではない。検索結果ページで再実行 |
| バッジに `ERR` | DevTools コンソールで `[rentracks-scraper]` のログを確認 |
| アラート「セッションが切れた可能性があります」 | 再ログイン後にもう一度実行 |
| 行数が想定より少ない | 表示件数を 100 にしてから再実行 |
| 列に欠損が多い | サイト側のクラス名が変わった可能性。`content.js` の `parseAdvCard` を見て `th` ラベルが一致しているか確認 |
| Excel で文字化け | 既に BOM 付きで出力済み。直らない場合はスプレッドシートでインポートを推奨 |

## 既知の制限

- **ページサイズの自動切替には未対応**：100 件以外の表示で起動すると確認ダイアログが出る。100 件に手動で切り替えて再実行することを推奨
- LP URL（`<a href>`）はそのまま出力。リダイレクト先の実 URL は深掘りしない
- サイトの紹介文には掲載条件 (`metatable`) は含めない（別カラムに分離して出力するため）
