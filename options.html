Rentracks 案件一覧 設定

CSV 保存先サブフォルダ(Downloads 配下)
~/Downloads/<入力値>/ にダイアログ無しで保存します。
空欄なら ~/Downloads/ 直下に保存(サブフォルダ無し)。
使えない文字: \ : * ? " < > | / .. による親階層遡及も不可。
注: Chrome 拡張は ~/Downloads/ 外には保存できません(Chrome のセキュリティ仕様)。Desktop や Documents 等に保存したい場合は、保存後に Finder で移動してください。
自動実行スケジュール
制約:
・Chrome が起動していない時刻は発火しません(次回 Chrome 起動時に 1 回だけ遅延発火します)
・Rentracks にログイン済みである必要があります(セッション切れ時はエラー通知)
・bill_index タブがなければ自動でバックグラウンドで開きます
・OS の通知許可が必要です。macOS なら「システム設定 → 通知 → Google Chrome」で確認
・デバッグモードが ON のままだと自動実行も 1 件しか取りません(popup でチェックを外しておく)
Google スプシ連携
出力先
Apps Script Web App URL
GAS Web App デプロイ手順:
  1. 記録したいスプレッドシートを開く → メニュー「拡張機能 → Apps Script」
  2. Code.gs に下記コードを貼る
  3. 右上「デプロイ → 新しいデプロイ → 種類: ウェブアプリ」
  4. 実行ユーザー「自分」、アクセス権「全員」でデプロイ → 表示された URL を上記欄に貼る
function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName("rentracks") || ss.insertSheet("rentracks");
  const headers = ["取得日時", ...data.columns];
  if (sheet.getLastRow() === 0) sheet.appendRow(headers);

  const idColInData = data.columns.indexOf("プロダクトID");
  if (idColInData < 0) throw new Error("columns に プロダクトID がありません");
  const idColInSheet0 = idColInData + 1;
  const numCols = headers.length;
  const ts = new Date(data.timestamp);

  const lastRow = sheet.getLastRow();
  const existing = lastRow >= 2
    ? sheet.getRange(2, 1, lastRow - 1, numCols).getValues()
    : [];
  const idToIdx = {};
  for (let i = 0; i < existing.length; i++) {
    const k = String(existing[i][idColInSheet0] || "");
    if (k) idToIdx[k] = i;
  }

  const appends = [];
  let updated = 0;
  for (const row of data.rows) {
    const id = String(row[idColInData] || "");
    const full = [ts, ...row];
    if (id && idToIdx[id] !== undefined) {
      existing[idToIdx[id]] = full;
      updated++;
    } else {
      appends.push(full);
    }
  }
  if (existing.length > 0) {
    sheet.getRange(2, 1, existing.length, numCols).setValues(existing);
  }
  if (appends.length > 0) {
    sheet.getRange(sheet.getLastRow() + 1, 1, appends.length, numCols)
      .setValues(appends);
  }
  return ContentService
    .createTextOutput(JSON.stringify({ ok: true, written: appends.length, updated }))
    .setMimeType(ContentService.MimeType.JSON);
}
注:
・URL は「アクセス権: 全員」のため、知っている人なら誰でも書き込み可能。秘密扱いに
・スプシの 1 列目に「取得日時」が自動で入る。2 列目以降は CSV と同じ列順
・上書きモード: 既に同じ「プロダクトID」の行があれば最新値で上書き、新規だけ末尾追加
・出力先「スプシのみ」/「両方」で URL が未設定だとエラー通知が出る
