CSV 保存先フォルダ
任意のフォルダ(例: ~/Desktop/、~/Documents/ など)を選択できます。Chrome の File System Access 経由で書き込むため、Downloads 以外の場所にもダイアログ無しで保存されます。
クリアすると毎回保存ダイアログが開く動作に戻ります。
制約: ホームディレクトリ直下や ~/Library など Chrome がブロックする「機微なフォルダ」は選択できません(その場合は別のフォルダを選んでください)。ブラウザを再起動すると保存先フォルダへのアクセス権限が失われ、CSV取得時に再付与の確認が出ます。
